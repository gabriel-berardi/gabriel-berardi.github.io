# Terminal Reborn

A custom fork of [Terminal](https://github.com/panr/hugo-theme-terminal) theme for Hugo, enhanced for my own personal website at https://www.gabriel-berardi.com/.

> **Original Theme**: [Terminal by panr](https://github.com/panr/hugo-theme-terminal) - A simple, retro theme for Hugo

---

## About This Fork

Terminal Reborn is my personalized version of panr's excellent Terminal theme. While maintaining the core aesthetic and functionality of the original, I've made several enhancements to better suit my personal website and workflow.

## What's Changed & Improved

- Cleaned and reorganized parts of the codebase
- Improved design, e.g. for the table of contents and navbar
- Implemented LaTeX support via [KaTeX](https://katex.org/)
- Implemented image lightbox via [Fancybox](https://fancyapps.com/fancybox/)

## Original Features (from Terminal Theme)

Terminal Reborn retains all the great features of the original Terminal theme:

- Fully customizable color schemes generated by [Terminal.css](https://panr.github.io/terminal-css/)
- [Fira Code](https://github.com/tonsky/FiraCode) as default monospaced font
- Custom syntax highlighting based on [Chroma](https://github.com/alecthomas/chroma)
- Fully responsive design
- Fully based on Hugo ecosystem (Pipes and Modules)

### Built-in Shortcodes

- **`image`** (props required: `src`; optional: `alt`, `position`, `style`)
- **`code`** (props required: `language`; optional: `title`, `open`)

### Code Highlighting

Custom syntax highlighting based on Chroma. Wrap your code like this:

````markdown
```html
// your code here
```
````

## Installation

The theme needs at least Hugo **Extended** v0.90.0 or higher.

### As Hugo Module (Recommended)

```bash
# Initialize your module (if first time)
hugo mod init github.com/your-username/your-site

# Add the theme module
hugo mod get github.com/gabriel-berardi/hugo-theme-terminal-reborn
```

Then add to your `config.yaml`:

```yaml
module:
  imports:
    - path: github.com/gabriel-berardi/hugo-theme-terminal-reborn
```

### As Local Theme

```bash
git clone https://github.com/gabriel-berardi/hugo-theme-terminal-reborn.git themes/terminal-reborn
```

Then in your config:

```yaml
theme: terminal-reborn
```

### As Git Submodule

```bash
git submodule add https://github.com/gabriel-berardi/hugo-theme-terminal-reborn.git themes/terminal-reborn
```

## Configuration

Copy this basic configuration to your `config.yaml`:

```yaml
baseURL: "https://your-site.com/"
languageCode: en-US
title: Your Site
theme: terminal-reborn

pagination:
  pagerSize: 5

markup:
  goldmark:
    renderer:
      unsafe: true
    extensions:
      math: true
  tableOfContents:
    startLevel: 2
    endLevel: 2

params:
  dateFormat: "02-January-2006"
  contentTypeName: "posts"
  showMenuItems: 4
  fullWidthTheme: false
  centerTheme: true
  toc: true
  tocTitle: "Table of Contents"
  
  Logo:
    logoText: "Your Name"
    logoHomeLink: "/"
  
  social:
    github: "https://github.com/your-username"
    linkedin: "https://linkedin.com/in/your-username"
    mastodon: "https://mastodon.social/@your-handle"
    bsky: "https://bsky.app/profile/your-handle.bsky.social"

languages:
  en:
    title: Your Site
    params:
      subtitle: Your site subtitle
      keywords: your, keywords, here
      menuMore: Show more
      readMore: "> Read more "
      readOtherPosts: Read other posts
    menu:
      main:
        - identifier: home
          name: Home
          url: /
          weight: 1
        - identifier: about
          name: About
          url: /about
        - identifier: blog
          name: Blog
          url: /blog
        - identifier: links
          name: Links
          url: /links
```

## Usage

```bash
# Run the development server
hugo server -t terminal-reborn

# Build for production
hugo
```

## Customization

### Overriding Styles

Create a `static/style.css` file in your project root to override theme styles without modifying the theme files.

### Modifying Layouts

Copy any layout file from `themes/terminal-reborn/layouts/` to your project's `layouts/` directory and modify it. Hugo will use your version.
